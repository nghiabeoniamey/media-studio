## Gaps flagged by the verifier

- YouTube self-hosted publishing gotcha: if the Google OAuth consent screen stays in 'Testing' with external users, refresh tokens expire after 7 days (developers.google.com/identity/protocols/oauth2, updated 2026-05-26). Scheduled uploads would break every week. Moving the app to Production for the youtube.upload scope means passing Google's OAuth verification, which is separate from the YouTube API compliance audit that lifts the private-only restriction.
- TikTok's limits on unaudited clients go beyond 'private viewing'. Error 'unaudited_client_can_only_post_to_private_accounts' means the target account itself must be private. Postiz's docs, citing TikTok's guidelines, add that only up to 5 users can post per 24 h. With PULL_FROM_URL, media must be on a domain verified in the TikTok developer account, so R2 needs a custom domain on a domain you own, not r2.dev (developers.tiktok.com direct-post reference; docs.postiz.com/providers/tiktok).
- AI-content disclosure should be built into the Publisher interface. YouTube's API has status.containsSyntheticMedia (videos.insert/update, since 2024-10-30, per the YouTube revision history), and TikTok/Postiz expose a 'Video made with AI' flag. Realistic 'cinematic' Bible scenes would likely need these set.
- YouTube changed view counting on 2026-08-27. Public views now count from the first frame, while monetization and YPP eligibility use 'Engaged views' and 'qualified Shorts views' (YouTube Data API revision history). The analytics and cost-per-view module should track engaged views, not raw views.
- Upload-Post Basic at $16/mo ($192/yr) has unlimited uploads and 5 profiles, which covers up to 5 niches at half the Professional price. The Free tier's platform list does not include TikTok. The $33 Professional price is the annual-billing rate.
- Temporal Cloud's Developer plan adds a 10% support surcharge on usage. Each Schedule execution costs 3 actions, and heartbeats and retries are billed. Polling-based waits for video jobs multiply the action count, so prefer async completion or webhooks.
- Inngest Free has no overage: executions pause when the 50k quota is reached, and trace history lasts only 24 h. Trigger.dev Free stops after its included $5 credit. Both affect the budget-guard and alerting design.
- Contabo describes its Core VPS tier as being for workloads where 'CPU is rarely the bottleneck'. Remotion and FFmpeg rendering is CPU-bound, so benchmark Core against the Performance tier (Cloud VPS Plus 4 at €10.80, Plus 6 at €15.20 effective) before committing to a 24-month prepay.
- Hetzner's official prices exclude IPv4 (about €0.50/mo more) and VAT. Hetzner Object Storage was not touched by the June round, but it is currently degraded in HEL1 (status.hetzner.com, since 2026-09-09).
- Modal's GPU prices carry multipliers: 1.15–1.75x for region selection and 3x for non-preemptible execution, with CPU and memory billed on top. This matters for any later serverless ComfyUI worker.
- The bullmq.io homepage now advertises 'Redis and PostgreSQL', while the docs still describe a Redis-only design. Confirm whether a Postgres backend really exists before using it to avoid running Redis.
- Remotion Free License headcount includes outside contractors or agencies who work on the same Remotion project. If the solo operator later hires 3 or more editors or developers who touch the Remotion code, a Company License (from $100/mo) is needed.
- Instagram API publishing is capped at 100 API-published posts per rolling 24 h per account (Meta content-publishing docs, per search results). This is not a constraint at 2–3 videos/day per niche, but the publisher should still enforce it.
