## Gaps flagged by the verifier

- YouTube restructured its monetization policy on 2026-07-16 (in the last 3 months) into 'Generic or Repetitive Content', 'Unsatisfying or Off-putting Content' and 'AI Personas Related to Sensitive Topics'. The new off-putting category targets 'emotionally manipulative formulas' and 'videos that stitch together unrelated or inconsistent AI clips'. It explicitly allows 'using AI to visualize a unique character and narrative you invented'. The format spec should be checked against this exact language. Avoid an AI 'pastor/priest' persona giving life, health or financial advice, because that falls under the sensitive-topics category. https://support.google.com/youtube/answer/1311392?hl=en ; https://techcrunch.com/2026/07/20/youtube-clarifies-policies-around-ai-slop-and-upsetting-videos/
- Official rule that matters for the 1–3 min SKU: any Short over one minute with an active Content ID claim of any type, including manual claims, is blocked globally and cannot be monetized. Music must come from sources that do not register Content ID (e.g. the YouTube Audio Library), or the channel must be allowlisted. Some 'royalty-free' stock libraries do register Content ID. https://support.google.com/youtube/answer/15424877?hl=en
- Meta app setup is unresolved. Business-type apps have no Development/Live toggle ('Business apps rely on access levels instead of modes'). Use-case apps have a 'Publish > Go live' requirements list. The App Modes doc says Live-mode apps get 'only permissions approved through App Review'. So 'Standard Access, no App Review' plus 'must be Live for public posts' may conflict depending on which app type is created. Prototype on a test Page and check that a non-role account can see the API-posted reel. https://developers.facebook.com/docs/development/create-an-app/app-dashboard/ ; https://developers.facebook.com/docs/development/build-and-test/app-modes
- Facebook monetization changed in 2025. In-stream Ads, Ads on Reels and the Performance Bonus ended 2025-08-31 and were replaced by the invite-only Content Monetization program. The current official list has 70 countries and excludes Vietnam (render on 2026-10-09). Many blogs and Facebook posts still circulate an older 72-entry list that includes Vietnam, which is misleading. https://www.facebook.com/business/help/1049081556813520 ; https://www.facebook.com/business/help/267128784014981
- Made-for-kids risk for the planned 3D Pixar-kitten niche. Such content is likely to be treated as 'made for kids' (COPPA), which brings no personalized ads, disabled comments and lower RPM. YouTube's kids quality principles ('Hard to follow… often the result of mass production or autogeneration', 'Strange use of children's characters') can suspend YPP for the whole channel. The publisher must set status.selfDeclaredMadeForKids correctly per video. https://support.google.com/youtube/answer/1311392?hl=en
- Biographies niche: YouTube requires AI disclosure when content 'Makes a real person appear to say or do something they didn't do'. Meta requires labels for photorealistic video or realistic audio. Realistic AI depictions of real historical or living people therefore need the AI flag even in the 'illustration' preset if it is photorealistic. https://support.google.com/youtube/answer/14328491?hl=en
- YouTube's AI-disclosure examples list 'AI generated music' plainly as needing disclosure, not only when it is the 'main focus'. If AI music (e.g. Suno) is used, set containsSyntheticMedia=true. Separately, cloning one's own voice does not need disclosure, while a generic realistic TTS narrator on YouTube is not addressed. https://support.google.com/youtube/answer/14328491?hl=en
- YouTube upload quota is per Google Cloud project (100 videos.insert calls/day), not per channel. One project serving all niche channels shares that cap. The Quota Calculator's auto-generated summary still says videos.insert costs 1600, so do not rely on the summary text. https://developers.google.com/youtube/v3/determine_quota_cost
- Several key official docs changed in the last ~3 months and should be re-checked before build. FB Reels Publishing guide: Jul 30, 2026. TikTok Content Sharing Guidelines: Aug 4, 2026. TikTok Direct Post reference: Aug 24, 2026. IG User Media reference and IG Platform overview: Sep 28, 2026. YouTube Quota Calculator: Sep 15, 2026. Also, the IG Content Publishing page still contradicts itself (100 vs 50 per 24h), so treat content_publishing_limit as the source of truth.
- Meta's official AI-label help page (updated ~20 weeks ago) still describes the old 'AI creator' profile label, so Meta's help docs lag the 2026-08-31 Instagram rename. The 'AI-generated profile' label only matters if a niche uses a recurring AI 'person' or host persona. https://www.meta.com/en-gb/help/artificial-intelligence/1783222608822690/
- The X pay-per-use price includes $0.20 per post containing a URL (official). Any CTA links on X cost 13x more than a plain post. https://docs.x.com/x-api/getting-started/pricing
